## What was measured

- **On the ground, the UHF mast gave the best result of any run:** PCI 204 at +14.0 dB (A0) and +14.1 dB (A0b), tracked 77–84 s of 89.5 s in 1–2 arcs. Two spots, 34 minutes apart, 0.1 dB apart.
- **On the chair, the same mast tracked nothing above the detection floor** (A1, A2): every cell at −10.4 to −11.6 dB, within 3 dB of the −12.9 dB threshold, with 21–54 arcs per cell.
- **Same spot, ground vs chair** (A0b vs A1): PCI 204 went from −11.6 dB (floor) on the chair to +14.1 dB on the ground, a difference of at least 25.7 dB. The floor value is an upper bound on the chair SNR (see below), so the true gap may be larger.
- **On the chair, Bingfu and telescopic each tracked one cell above the floor:** Bingfu vertical (B2) PCI 220 at +6.1 dB, Bingfu horizontal (B) PCI 220 at +5.1 dB, telescopic (C) PCI 204 at +6.1 dB. Bingfu and telescopic picked different strongest cells at the same spot.
- **Run-to-run floor (A1 vs A2, same antenna, same spot):** no above-floor cell in either, and the cell sets differ (A1 three cells, A2 only PCI 244). For marginal cells this pair shows that which cells appear changes run to run, so a few dB at the floor means nothing. A2's base was held, A1's was not. The only above-floor repeat is A0 vs A0b (0.1 dB), on the ground at two spots.
- **Capture level:** ground runs had RMS 16–23 LSB and ≤ 0.06 % clipped values; chair runs had RMS 38–55 LSB and 1.4–6.8 % clipped (C the most). With auto gain, the chair runs saw more total power or a different gain.

## What it does not show

The antenna comparison is **confounded by mounting**. Bingfu and telescopic were never tested on the ground, and the UHF mast's 25 dB difference between ground and chair at the same spot is larger than any difference between antennas on the chair. Possible causes, none measured (`TBC`): the magnetic-base whips need a ground plane, which a plastic chair does not give; overload or clipping at auto gain on the chair; the hand on the base. "The UHF mast is about 17 dB worse than the Bingfu" is therefore not a result.

The SNR is the front end's tracking estimate, averaged over the epochs that passed detection only. Near the threshold it reads at or just above the threshold whatever the true SNR is: a `floor` value is an upper bound, and differences between floor values are not meaningful.

One run per configuration, 90 s each, one EARFCN, one site, auto gain.
